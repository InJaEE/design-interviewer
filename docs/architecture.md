# Codex 디자인 인터뷰 하네스

## 목적

Codex 대화를 인터페이스로 사용해 이력서 검토, 포트폴리오 검토, 경력 면접, 프로젝트 심층 면접, 역량별 면접, 평가 근거 검토와 면접 결과 보고서를 순서에 관계없이 실행한다.

각 기능은 현재 존재하는 자료만 사용하며 결과를 공유 증거 저장소에 누적한다.

## 작업공간 경계

- 면접관용 비공개 작업공간: 원본 자료, 분석, 질문 전략, 평가와 보고서
- 지원자용 면접 작업공간: 공개 안내, 질문, 답변과 진행 상태
- 코칭 작업공간: 연습 답변, 힌트, 피드백과 개선 답변

Codex 작업 분리만을 보안 경계로 간주하지 않는다. 지원자용 작업공간에는 내부 평가 기준이나 비공개 메모를 복사하지 않는다.

## 비선형 실행

완료 순서를 기록하는 단일 진행률을 두지 않는다. 각 자료, 분석, 면접과 평가가 자신의 상태와 버전을 가진다. 새 자료가 추가되면 영향을 받는 결과만 `갱신 필요`로 표시한다.

## 평가와 코칭

- 평가는 시간 안에서 중요한 판단 근거를 수집하며 힌트와 즉시 피드백을 제공하지 않는다.
- 코칭은 답변 후 피드백, 권장 구조, 단계적 힌트를 제공할 수 있다.
- 평가 기록은 코칭에 활용할 수 있지만 코칭 기록은 평가에 활용할 수 없다.

## 판단 근거 흐름

1. 자료와 답변에서 사실과 주장을 추출한다.
2. 각 주장에 출처를 연결한다.
3. 지지하거나 반대하는 판단 근거를 연결한다.
4. 서로 맞지 않는 정보와 추가 확인 항목을 표시한다.
5. 고정된 직무·직급 기준으로 평가한다.
6. 근거와 신뢰도를 포함한 결과를 작성한다.
