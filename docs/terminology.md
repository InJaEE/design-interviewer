# 사용자용 용어 원칙

Codex 대화, 안내 문구, 명령 예시, 면접 결과 보고서에는 이 문서의 사용자용 명칭을 사용한다.
내부 ID는 파일명, 설정 참조, 호환성 유지 목적으로만 사용하며 사용자에게 직접 노출하지 않는다.

## 면접 및 코칭 유형

| 내부 ID | 사용자용 명칭 | 사용자용 설명 |
| --- | --- | --- |
| `grill-me-evaluator` | 심층 검증 면접 | 답변의 전제, 실제 기여, 의사결정 근거를 한 질문씩 깊게 확인한다. |
| `grill-me-coach` | 답변 심화 코칭 | 답변을 단계별로 점검하고 피드백과 개선 방향을 제공한다. |
| `career-interview` | 경력 면접 | 경력의 변화, 역할, 성장 과정과 이직 배경을 확인한다. |
| `project-interview` | 프로젝트 심층 면접 | 특정 프로젝트의 문제 정의, 기여, 의사결정과 결과를 깊게 확인한다. |
| `competency-interview` | 역량별 면접 | 선택한 직무 역량을 중심으로 경험과 행동 근거를 확인한다. |

## 면접관 스타일

| 내부 ID | 사용자용 명칭 |
| --- | --- |
| `warm-explorer` | 편안하게 대화하는 면접관 |
| `balanced-practitioner` | 균형 있게 살펴보는 면접관 |
| `probing-product-lead` | 깊이 파고드는 프로덕트 리드 |
| `ux-specialist` | 사용자 경험을 중점적으로 보는 면접관 |

| `skeptical-verifier` | 성과와 기여를 꼼꼼히 보는 면접관 |
| `grill-me-evaluator` | 답변을 끝까지 검증하는 면접관 |

## 일반 용어

| 사용하지 않을 표현 | 사용자용 표현 |
| --- | --- |
| 인터뷰어 프리셋 | 면접관 스타일 |
| 오버라이드 | 세부 설정 |
| Evidence Review | 평가 근거 검토 |
| 증거 충분성 | 판단 근거의 충분성 |
| 상충하는 증거 | 서로 맞지 않는 정보 |
| 미검증 주장 | 추가 확인이 필요한 내용 |
| 인터뷰 세션 | 면접 |
| 세션 재개 | 이어서 면접하기 |
| 체크포인트 | 이어하기 정보 |
| Session Transfer | 면접 기록 가져오기 |
| Hiring Report | 면접 결과 보고서 |

## 작성 기준

- 내부 구조가 아니라 사용자가 수행할 행동을 표현한다.
- 불필요한 영어와 기술 용어를 피한다.
- 지원자를 공격하거나 의심하는 인상을 주는 표현을 피한다.
- 평가와 코칭을 이름만으로 구분할 수 있어야 한다.
- 면접관 스타일은 중점적으로 살펴볼 영역이나 대화 방식을 드러낸다.
- 내부 ID가 오류 메시지나 사용자 응답에 그대로 노출되지 않게 한다.
