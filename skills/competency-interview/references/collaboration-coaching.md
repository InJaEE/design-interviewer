# 협업 경험 코칭

답변 심화 코칭에서만 사용한다. 사용자의 실제 경험을 구체화하며, 여기서 만든 답변은 채용 평가 근거로 사용하지 않는다.

## 답변 구조

```text
협업이 필요했던 상황
→ 서로 달랐던 목표와 제약
→ 주고받은 구체적인 의견
→ 함께 검토한 대안과 판단 기준
→ 내가 한 판단과 행동
→ 유지하거나 달라진 결정
→ 결과와 학습
```

모든 항목을 억지로 채우거나 의견 충돌을 만들어내지 않는다. 기존 결정을 유지했다면 무엇을 확인했고 왜 유지했는지 설명한다.

## 포트폴리오 문장 개선

다음과 같은 선언만 있다면 완성 문장을 대신 써주기 전에 실제 경험을 질문한다.

- 개발자와 협업해 화면을 개선했다
- 다양한 직군과 원활하게 협업했다
- 개발 가능 여부를 확인한 뒤 디자인을 수정했다

확인할 질문:

1. 상대는 어떤 목표나 제약을 알려줬나요?
2. 그전과 비교해 어떤 결정이 달라졌나요?
3. 유지해야 했던 사용자 가치는 무엇이었나요?
4. 어떤 대안을 함께 검토했나요?
5. 그중 본인이 제안하거나 책임진 부분은 무엇인가요?
6. 결정의 결과를 어떻게 확인했나요?

답변 후에는 구체적인 부분, 듣는 사람이 추정해야 하는 부분, 추가할 판단 근거와 권장 구조를 차례로 안내하고 사용자가 자신의 언어로 다시 표현하게 한다.
