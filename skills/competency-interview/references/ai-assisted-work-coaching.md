# AI 활용 경험 코칭

답변 심화 코칭에서만 사용한다. 사용자의 실제 경험을 구체화하고 특정 AI 도구 사용을 권장하거나 과장하지 않는다. 여기서 만든 답변은 채용 평가 근거로 사용하지 않는다.

## 답변 구조

```text
프로젝트 상황과 AI를 사용한 이유
→ AI에게 맡긴 구체적인 작업
→ AI가 만든 결과
→ 내가 다시 확인한 내용
→ 검토하거나 제외한 대안
→ 선택에 사용한 기준
→ 내가 수정하거나 최종 결정한 부분
→ 결과를 확인한 방법
→ 한계와 학습
```

모든 항목을 억지로 채우지 않는다. AI 제안을 그대로 채택했다면 다른 결과를 만들었다고 꾸미지 말고, 왜 적절하다고 판단했는지 설명한다.

## 포트폴리오와 답변 구체화

다음과 같은 표현만 있다면 완성 문장을 대신 작성하기 전에 실제 경험을 질문한다.

- AI로 사용자 인터뷰를 분석했다
- AI로 다양한 시안을 만들었다
- 생성형 AI로 화면 또는 카피를 제작했다
- AI를 활용해 생산성을 높였다

확인할 질문:

1. AI에 어떤 작업을 맡겼나요?
2. 생성된 결과에서 무엇을 직접 다시 확인했나요?
3. 선택하지 않았거나 크게 수정한 결과가 있었나요?
4. 최종 선택에 사용한 기준은 무엇이었나요?
5. AI 사용으로 실제 디자인이나 업무 방식이 어떻게 달라졌나요?
6. 결과를 어떻게 확인했고 무엇을 추가로 수정했나요?
7. 확인하지 못한 한계나 위험은 무엇이었나요?

## 피드백 방식

1. AI 사용 범위가 명확한 부분
2. 사람의 판단과 행동이 보이지 않는 부분
3. 대안과 선택 기준이 빠진 부분
4. 검증과 결과의 연결이 부족한 부분
5. 권장 답변 구조
6. 사용자가 자신의 언어로 다시 답할 기회

예시는 사용자의 실제 경험과 명확히 구분되는 짧은 가상 사례로만 제공한다. 도구 이름이나 프롬프트보다 판단과 책임을 중심으로 피드백한다.
