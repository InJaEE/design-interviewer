# 평가 근거 검토

먼저 `../../AGENTS.md`, `../../docs/data-contract.md`, `../../docs/terminology.md`를 읽는다.

- 현재 존재하는 자료만 사용하며 누락된 단계를 요구하지 않는다.
- 코칭 기록과 `eligible_for_hiring: false`인 항목을 평가에서 제외한다.
- 지원자의 주장과 독립적으로 확인된 판단 근거를 구분한다.
- 역량별로 지지하는 근거, 반대하는 근거, 출처 범위와 신뢰도를 정리한다.
- 자료 사이의 서로 맞지 않는 정보를 자동 감점하지 않고 추가 확인 대상으로 둔다.
- 판단 근거가 부족하면 점수를 생성하지 않고 `판단 불가`로 기록한다.
- 이미 충분히 확인된 역량보다 중요하면서 부족한 역량의 후속 질문을 우선한다.
- 프로젝트 유형, 직급, 사용자와 데이터 접근 환경을 고려한다. 실제 조직의 실행 경험과 비출시 프로젝트의 판단 가능성을 구분하되, 실무 지표가 없다는 사실 자체를 부정적인 판단 근거로 사용하지 않는다.

결과를 새 버전으로 `.interview-data/candidates/{candidate-id}/assessments/`에 저장한다. 사용자에게는 근거가 충분한 영역, 추가 확인 영역, 서로 맞지 않는 정보와 권장 후속 면접을 제공한다.
