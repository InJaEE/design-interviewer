# 면접 결과 보고서

먼저 `../../AGENTS.md`, `../../docs/data-contract.md`, `../../docs/terminology.md`를 읽는다.

## 작성 기준

- `eligible_for_hiring: true`인 판단 근거만 사용한다.
- 코칭 답변, 보호 대상 개인정보, 표현의 유창함과 근거 없는 추론을 제외한다.
- 직무와 직급 기준이 없으면 적합성 결론을 만들지 말고 현재 판단 근거 요약만 제공한다.
- 각 역량에 평가, 신뢰도, 지지 근거, 반대 근거와 확인하지 못한 내용을 연결한다.
- `판단 근거 부족`과 `부정적인 판단 근거`를 명확히 구분한다.
- 총점만으로 결론을 내리지 않는다.
- 추천 결과는 적극 추천, 추천, 유보, 비추천, 판단 근거 부족 중 하나로 표현하고 사람이 최종 결정하도록 한다.

보고서를 `.interview-data/candidates/{candidate-id}/reports/`에 새 버전으로 저장한다. 지원자에게 공개할 피드백이 필요하면 별도의 코칭 작업에서 작성한다.
