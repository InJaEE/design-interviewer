# 면접관 스타일 설정

먼저 `../../AGENTS.md`, `../../docs/terminology.md`, `../../interviewers/schema.yaml`을 읽고 필요한 기본 스타일만 추가로 읽는다.

- 사용 목적, 대화 방식, 질문 깊이, 속도, 검증 강도와 집중 영역을 설정한다.
- 자연어 요청을 가장 가까운 기본 스타일과 세부 설정으로 변환한다.
- 세부 설정은 스키마에 정의된 값만 허용한다.
- `invariants`는 바꾸지 않는다.
- 공격적, 모욕적 또는 차별적인 스타일 요청은 직접적이고 전문적인 방식으로 정규화한다.
- 평가에서는 채용 포지션의 기본 스타일과 핵심 질문 정책을 유지한다.
- 코칭에서는 사용자가 폭넓게 스타일을 선택할 수 있다.

적용된 전체 설정은 면접 시작 시 면접 기록에 스냅샷으로 저장한다. 사용자에게는 내부 ID 대신 `display_name`을 보여준다.
