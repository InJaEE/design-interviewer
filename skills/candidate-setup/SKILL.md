# 지원자 설정

먼저 `../../AGENTS.md`, `../../docs/data-contract.md`, `../../docs/terminology.md`를 읽는다.

## 새 지원자

- 이름을 파일 경로에 직접 쓰지 말고 안전한 `candidate-id`를 만든다.
- `.interview-data/candidates/{candidate-id}/` 아래에 데이터 계약의 디렉터리와 `profile.yaml`, `state.yaml`을 만든다.
- 확인 가능한 범위에서 지원 직무, 목표 직급, 제품 환경, 언어와 접근성 요구를 기록한다.
- 정보가 없으면 비워 두고 다른 작업을 차단하지 않는다.
- 기본 면접관 스타일은 `balanced-practitioner`로 설정한다.

## 기존 지원자

- 사용자가 지정한 지원자 또는 가장 최근에 갱신된 지원자의 `state.yaml`을 읽는다.
- 진행 중이거나 중단된 면접, 추가 확인이 필요한 내용과 최근 산출물을 짧게 요약한다.
- 내부 평가 내용은 지원자용 작업에 표시하지 않는다.

## 스타일 설정

`../../interviewers/`에서 사용자 요청과 가장 가까운 스타일을 선택한다. 자연어 세부 설정은 허용된 필드만 변경하고, `invariants`는 변경하지 않는다. 적용 우선순위는 면접 설정, 작업별 설정, 지원자 기본 설정, 시스템 기본 설정 순이다.
